# v4.0.0 章节限定分布最终复核

日期：2026-11-26。版本仍为 v4.0.0。本组验证章节附加限定的数量和分布要求：一般 0—3 项作为参考，超过三分之一的正文段落含附加限定时须按严重堆叠处理，同时保护主张本身不可省的条件与事实。

[输入](input.md)包含五项合成任务：只有两项但占比已达 2/5 的小节、含真实工况与操作前提的段落、四种故障原因的专题、两段短小节、已有统一工况却逐段重复提醒的章节。执行前保存[判据](rubric.md)，不向执行者提供。

执行者在独立上下文读取当前技能、必要指南和任务输入，不读取判据或历史输出。实际答复见[output.md](output.md)，读取收据见[loaded.json](loaded.json)，首轮规则集合摘要见[runtime-snapshot.json](runtime-snapshot.json)。逐项评阅见[review.md](review.md)，工程和文件核验见[checks.json](checks.json)。

首轮 B—E 四题通过。A 题的润色稿删去了两处多余提醒，审阅意见遗漏了整节的问题程度。修订审阅规则后，另用独立上下文重做[同一道 A 题](recheck-input.md)。复测的[实际输出](recheck-output.md)、[加载记录](recheck-loaded.json)和[最终规则摘要](recheck-runtime-snapshot.json)单独保存。

此前的 [v4.0.0 验证](../v4-release-2026-11-26/README.md)保留原输出和冻结摘要，不冒充本次规则下的重测。A 题属于已知问题的回归复测。规则及输出由模型执行和评阅，不代表人工受试评价或未知稿件准确率。

归档摘要采用 CRLF 转 LF 后的 SHA256，覆盖输入、输出、判据、评阅、加载记录和规则快照；README、checks 和清单自身不纳入。实际输出不事后改写。

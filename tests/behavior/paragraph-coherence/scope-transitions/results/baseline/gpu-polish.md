5.3 GPU–GPU通信类型

GPU 间的通信包括点对点复制、远程 load/store、远程原子、集合通信、分布式队列与数据依赖通知。本节重点比较显式复制与远程读写。远程 load 适合由消费端确定数据需求，但可能形成请求—响应依赖；远程 store 或 put 适合由生产端推送数据，但需要目标空间和完成语义。显式复制有启动成本，但能使后续计算访问本地数据。

选择通信机制前，需核实以下信息：数据是否连续、是否重复使用、消费端能否提前预知数据需求、是否允许分块、是否需要多个写者，以及能否将所有权交接推迟到阶段边界。在比较复制与远程访问时，若缺少这些信息，仅比较“零拷贝”和“拷贝”的名称没有工程意义。

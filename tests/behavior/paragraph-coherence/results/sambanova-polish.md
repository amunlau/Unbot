### 1.1.2 产品形态与应用场景

在系统交付中，RDU 的执行能力需通过服务器、软件与服务提供给用户。SambaNova 的交付层次包括 RDU 芯片、SambaRack 系统、SambaStack 软件和 SambaCloud 云端推理服务。SambaRack 组织计算节点、主机、存储及网络；SambaStack 是 SambaNova 当前面向客户授权的推理软件栈，提供服务、监控和用户管理功能，并向应用提供 OpenAI 兼容接口。应用开发者通过 API 接入服务，模型开发者则编译、调优 RDU 模型；两者对应不同的使用层次[4,7,8]。

SambaNova 的这套产品与服务整体上主要面向交互式代码助手、长输出推理、多模型服务，以及需要本地部署的企业和科研任务。这些应用常同时受到单用户生成速度、上下文容量和多请求并发的约束，单纯增加峰值矩阵算力未必能改善响应时间。因此，系统设计既要保证单步生成的数据供给，也要安排不同请求和不同推理阶段所用的资源。2026 年 11 月，SambaNova 与 Supermicro 宣布共同开发和销售结合 GPU 与 SN50 RDU 的分离式推理系统，初始规划涉及 10,000 颗 SN50，由 Supermicro 承担系统集成、测试、交付和支持。该数量属于合作规划，不能视为已交付数量，也不能据此推断实际市场占有率[9]。

# 中文段落与话题承接行为检查

本目录用于检验段落组织、指代恢复、句间推进、编辑权限和保真结果。`cases.json` 集中保存输入、任务与评阅判据，不新增关键词扫描器。SambaNova 原文来自用户提供的失误案例，其产品、时间、数量和引文未在本任务中外部核实；其余内容均为合成材料，不能当作研究事实引用。

## 隔离执行

先冻结待测技能规则，再导出输入。执行者只收到当前技能入口、自己的输入文件和输出方式，可以读取技能运行参考；不得读取本目录的 JSON、其他任务、评阅判据或既往结果。评阅者随后核对实际输出，不要求唯一措辞。执行者与评阅者分离不等于双盲实验。

在仓库根目录用 Python 运行以下代码，输入将输出到临时目录，不污染工作树。只导出任务要求和原始材料，不导出 `reviewer_checks`。`heldout` 的内容应在规则冻结后首次提供给执行者和评阅者；若依据该案例修订规则，后续复测须称为回归检查，不能继续宣称未见材料。

```python
import json
import tempfile
from pathlib import Path

suite = json.loads(Path("tests/behavior/paragraph-coherence/cases.json").read_text(encoding="utf-8"))
output = Path(tempfile.mkdtemp(prefix="unbot-paragraph-inputs-"))
for task in suite["tasks"]:
    parts = [suite["execution_scope"], task["request"]]
    parts.extend(suite["materials"][key] for key in task["material_ids"])
    target = output / (task["id"] + ".md")
    target.write_text("\n\n---\n\n".join(parts) + "\n", encoding="utf-8")
    print(task["id"], target)
```

给独立执行者的请求可用：

> 使用指定的 Unbot `SKILL.md`，完成所附输入中的用户任务。只读该输入及必要的运行参考，不读测试目录、历史输出或预期判据。仅在最终答复交付结果，不另建文稿或断点；若有必须询问的事项，在答复中列出。不得修改技能文件。

## 任务与覆盖

| ID | 用途 | 重点检查 |
| --- | --- | --- |
| `sambanova-review` | 原例只审阅 | 多候选回指、搭配、段内任务变化、信息归属、不能替作者消歧 |
| `sambanova-polish` | 标准润色 | 对象已有作者答复后修复局部表达；跨段建议与实施权限分开 |
| `sambanova-structure` | 指定小节内结构整理 | 自然语言授权、标题保护、句段重组、引文与规划状态保真 |
| `boundary-review` | 13 个独立短片段 | 正常代词、省略、多主体与多时间、面积与功耗比较、场景到设计要求、摘要、段中主体、限定、真实换行、PPT 阅读前提、话题已由标题引入 |
| `material-authoring` | 从乱序记录起草 | 自主安排段落、准确的对象和流程、试验边界与合作计划、专业书面语 |
| `heldout` | 独立领域首次试用 | 不向规则编写者预送内容；冻结后检查实际判断和保留结果 |
| `listing-review` | 综合列举与严格分类复查 | 区分用途概述、同维度分类与面积/功耗多指标比较 |

上述任务共同覆盖用户要求的 14 类边界。普通润色与结构整理共享原稿和作者补充信息，以便比较权限影响；只审阅任务不提供补充消歧答案。`boundary-review` 中的换行材料只是结构摘录，不代表已经运行 Word、PPT 或 LaTeX 文件的保存、渲染或批注定位测试。

## 评阅与记录

逐项对照 JSON 中的评阅判据，记录原始输出、实际发现、遗漏、误报及不确定项。优先核对对象和关系是否读得清楚、必要信息是否完整、编辑权限是否遵守。改写不是越多越好，能保留的准确表达应稳定；同一根因也不要求重复出具意见。

允许不同的合格段落组织和措辞。不能凭输出出现“指代”“段落”、特定分类标签或某个连接词就判通过；也不能因字数、段数或标注数量与示例不同就判失败。检查原文与最终稿中的事实、限制、引文支持范围及原生结构保护是否一致。

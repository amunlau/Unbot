# PPT 必要定义与实际讲解路径复测

2026-11-20 提交前审查发现，部分条文绝对要求必要定义可见，另一些条文允许有明确时序的现场讲解。修订统一按实际使用路径判断，保留独立分发的自足要求，以及页面主张不能由口头限定修复的边界。

## 执行方法

先冻结技能入口与17份参考文件，再让一个独立上下文执行[完整输入](input.md)，只读取冻结规则和该输入，不提供预期结果、疑似错误或历史输出。材料为主执行者编写的四份合成摘录，四项在同一次任务中完成；执行者不是规则审查者。未开展多模型、重复采样或统计准确率评估。

[原始答复](result.md)逐字节归档，未润色为范文。规则摘要及原始、LF归档指纹见[runtime-snapshot.json](runtime-snapshot.json)。规则集合摘要按排序后的POSIX相对路径、NUL和单文件SHA-256拼接，各项用LF连接且无末尾换行，再计算SHA-256。归档指纹仅把CRLF换成LF，不去除空白或调整正文。快照用于标识本次实际执行规则，不随以后版本更新。

首次冻结后，同步了 `references/format-review.md` 页首的标准状态复核日期，并将相同的现场讲解例外补齐到 `SKILL.md` 的制作要求，消除主入口与细则的最后一处不一致。随后再次冻结规则，让同一执行上下文重做相同任务，未向其提供评阅结论或预期答案。[最终原始答复](final-result.md)和[最终规则快照](final-runtime-snapshot.json)单独保存，未覆盖首次输出。这是同一上下文的回归复测，不作为另一组独立样本；最终快照已与提交前的18份运行规则逐一核对一致。

主执行者对照输入与原始输出核对了对象、24个样本的定义、8 ms限值、7.2 ms观测值、工况、只审阅权限及计划/实际的区别。四项均保留原稿，只给出意见；没有增加版面判断或声称验收实际放映。

本次是文字摘录的判断复测，没有制作或打开PPT文件，也没有验证版式、动画、实际讲解执行或客户端兼容性。它补充规则检查，不能替代真实文件交付前的显示验收。

归档说明：历史规则文件的摘要与原集合 `sha256` 保留；公开的 `files` 仅列运行规则子集，新增 `published_collection_sha256` 只校验该子集，历史执行未重新运行。元数据范围见[行为验证索引](../README.md)。

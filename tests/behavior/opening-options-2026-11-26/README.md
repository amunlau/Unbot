# 段首可选写法的行为复测

日期：2026-11-26。技能版本：v3.3.0。针对六类段首写法、连续段落的功能选择和表达保真进行专项检查。

[输入](input.md)包含四项任务：从合成记录生成三段缓存说明；为日志压缩段落选择两个入口；审阅必要条件与频率被强化的候选；保留准确的定义和操作段落。按[判据](rubric.md)核对事实、限定、段间推进和过度修改，不要求复现指南措辞或固定段首顺序。

执行者在独立上下文读取技能及题内材料，不读取判据或历史输出。实际答复先写入仓库外隔离工作目录，再原样归档到[output.md](output.md)；[loaded.json](loaded.json)记录实际读取规则与输入的摘要，[runtime-snapshot.json](runtime-snapshot.json)保存最终规则集合摘要。逐项判断见[review.md](review.md)，文件检查见[checks.json](checks.json)。

四项输出符合各自判据：连续段落入口明确，非缓存场景能选用合适写法，必要条件和频率强化得到识别；准确的定义与操作段落原样保留。实际读取八份规则，摘要已与最终规则快照及输入对应。

这是一轮合成文字执行，包含同类回归情境和非缓存情境；没有进行重复采样、新旧版本效果对比、真实长稿重写或Office版面验收。归档与格式检查不替代语义评阅，旧用例与摘要保持不变。

归档摘要采用CRLF转LF后的SHA256，保护输入、实际输出、判据、评阅、加载记录与规则快照；README、checks和清单自身不纳入。输出不作事后改写。

## 输入与执行范围

[输入](input.md)包含三个合成文字任务：A 为跨对象比较起草，B 为保持分段与独立信息的标准润色，C 为含独立图注、操作警示及英文被动句的边界短稿审阅。A 包含连续小节与全文选择问题，仍是小规模任务，不代表真实数十页报告。

两位独立上下文执行者分别读取修改前与候选规则及同一份输入，不提供预期答案、另一版输出或优化分析。规则指纹见[runtime-snapshots.json](runtime-snapshots.json)，实际读取文件由各执行者记录在结果目录。测试输入只要求 Markdown 文字，不执行 Office 文件与断点流程。输入及预期检查与规则设计同属本轮开发材料，不称为未见留出集或双盲实验。

## 评阅关注点

先检查对象、数值、条件、证据强度与修改权限，再评阅全文比较、后段是否利用已知前提、动作关系与制作说明归属。独立负结果、未知执行者、图示范围与来源必须保留；减少写入次数不代表已测能耗收益。正常表达不因三项步骤、独立图注的重复或被动句被标错。允许多种合格组织，不按字数或固定句式评分。C 中是否存在其他可定位问题仍须独立判断，不能预设零项；其中末句重述顺序等内容使它不适合作为严格的全正常阴性样本。

## 实际结果与修订

[独立文字评阅](output-review.md)只读取输入和两份输出，不预设哪版更好。两版均完成比较任务，保留数值、未测工况、未知执行者及采购状态；C 正文均逐字保留。候选版更明确地将断电适用性写成条件判断，独立图注补充误差参照物的建议有任务依据。

候选版也增加了一条必要性不足的合段建议，以及一条应谨慎区分强调用途与可选压缩的尾句意见。主执行者据此收紧 review-protocol 的既有判断标准：更多显式说明、更紧凑或更少段落本身不构成立项理由，结构建议要解释其解决的具体障碍。该调整未改变完整论证优先或编辑权限。保留候选原始输出及评阅，不覆盖失败或分歧记录。

最终仅针对受影响的 B/C 安排新独立上下文执行，结果见[最终 B/C 输出](results/final-bc.md)及[读取清单](results/final-bc-loaded.json)。A 未因审阅建议标准细化而重复运行；最终规则指纹另存为 final，不冒称此前输出由最终规则生成。主执行者逐项回读最终 B/C：B 保留原标题、四段及全部独立信息，只建议分开图示与导出验证事项，未再提出主题相近即合段的建议；C 原文逐字保留，输出零项，未误改独立图注、警示或英文被动表达。但最终 C 同时未保留候选版有依据的图注参照物补全建议，因此不能将零项结果称为准确率提高。两次执行存在判断波动，最终复测只支持此次权限与保真边界未失守、所观察的额外合段建议未再出现，不证明规则已消除漏报或稳定改善真实长稿。

[独立规则审查](rule-review.md)另发现两处教学例保真偏移，均已修正并经回查确认。程序检查与文字评阅分别验收，不把单次对照写成稳定提升率。

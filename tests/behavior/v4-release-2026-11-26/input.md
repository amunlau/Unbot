- 采集线程为每条记录添加递增序号，并把记录放入内存队列；写入线程按入队顺序取出。
- 写入线程累计到 256 条记录，或距上次落盘达到 20 ms 时，将当前批次写入磁盘；两个条件任一满足即触发。
- 写入成功后，系统更新已落盘序号。重启时，采集端从这个序号之后继续发送，接收端按记录序号去重。

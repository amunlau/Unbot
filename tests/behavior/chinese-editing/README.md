# 中文编辑行为检查

本目录为 2026-11-18 中文优化提供可重复执行的合成任务。它们不含上游范例中的研究事实，也不是作者真实不满意稿件。用于检验具体边界及表达结果，不代表中文自然度基准或跨模型准确率。

## 执行方法

给独立执行者当前 `SKILL.md` 的路径和一个 `*-input.md`，让其按任务输出到隔离工作目录。只允许读取该输入及运行时技能参考文件，不提供本页、其他案例、预期结果、旧版结论或历史输出。执行者可以正常加载其所需的运行参考。随后由评阅者依据以下检查项核对实际输出。评阅者知晓规则，因此这是执行输入与预期分离的检查，不是双盲实验。

接受多种合格改写，不按固定措辞、词频或改动字数判通过；同时检查原有信息是否保留、是否新增无依据内容，以及表达问题是否得到改善。工具测试、行为检查和用户偏好分别记录。后续复用过的材料不再称为新持出样本。

## 核对要点（不给执行者）

### 标准润色

- 原标题默认保留，可在正文外提出建议。正文中与标题同义的起笔可以删。
- 长定语与弱动词应得到合理简化；35/55 °C 各 8 次、稳态、位置与参考温度计保留。
- 水介质和 60% 流量范围进入主张；同一段的无新信息免责可以删并，全流量未测仍保留。
- 稳定性与可靠性具有明确的不同含义，不能互相替代；0.26/0.18 °C、0.04/0.04 °C、48 h 及其归属准确。
- 保留计划状态、冷却前提、负责人、否定和命令。不能将作者样稿中的滤波器、负载响应迁入本稿。
- 现场验收保留为项目总结的原有记载，缺记录可在正文外提醒，不能擅自改成未验收。

### 材料起草及中英、汇报文字

- 中文报告、英文摘要和汇报文字的甲乙组数据、工况及研究状态一致；不补 p 值、百分比、机制或现场活动。
- 甲乙在误差与波动上各有结果，不能写成乙全面优于甲，也不把较小标准差直接推成已验证的长期可靠性。
- 不做的显著性、振动与长期试验仍能找到，既有具体边界自然表达，不凭空加泛泛局限或新研究安排。
- 选择尚未批准，原始文件保留及复核未完成的状态完整。
- 中文形成有信息推进的段落；三种文本均采用专业书面语。汇报页能独立识别工况与主要限制，备注不用于隐藏必要边界。

### 只审阅

- 全三页及备注纳入判断，正文不被替换。意见有原句、页位、大类和具体问题。
- 第 2 页无信息起笔及同阅读单元重复免责可标文风；第 1 页与独立第 2 页各自的空载条件不能被当作应删重复。
- 负载余量系数未定义、使用依据缺失，且影响后续电流选择，应明确定位并说明后果；不自行补公式。
- “采洋”应按文字问题定位。
- 第 3 页全负载主张超出已有试验；同批最大值 4.6/6.4 ms 冲突；现场验收记录待核。三类问题不可全写成笼统 AI 味，也不能据材料缺失断言活动虚构。
- 无渲染画面，不编造裁切、字号或重叠等格式问题；不根据模板感判定作者身份。

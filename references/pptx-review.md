# 在 PowerPoint 中标注原稿

交付一份带审阅意见的演示文稿副本。只审阅时保留各页正文、演讲者备注、母版、图表和原有评论。先按[演示文稿工作流程](presentation-workflow.md)实际读页，再用[全文衔接审阅](coherence-review.md)确认意见。是否值得标注由编辑结合前后文判断。

## 选择批注方式

- **当前编辑器支持现代批注。** 在副本中选中文字或对象、添加评论，再重开核对所指。若界面允许，可直接圈定文字范围。优先沿用现有批注体系，保留讨论线程和作者信息。不同 PowerPoint 版本对现代批注的支持有差异，应以重开的实际结果为准。[Microsoft 关于对象及文本锚点的说明](https://support.microsoft.com/en-us/powerpoint/modern-comments-in-powerpoint)
- **普通、尚无批注的 PPTX。** 随附的[页级批注工具](../scripts/review_pptx.py)使用经典原生批注。意见挂在相应幻灯片上，在“审阅／批注”窗格可查看。每条意见写明对象或表格行列、段落、引文及其段内位置。备注中的问题也挂在所属幻灯片上，位置注明“演讲备注”。这种批注在移动或改写原句后须重新定位。请向作者说明它是页级批注。[Microsoft 的演示文稿批注结构说明](https://learn.microsoft.com/en-us/office/open-xml/presentation/working-with-comments)
- **已有批注或文件受保护。** 对已有讨论，使用能保留原线程的编辑器审阅副本。若需维持签名有效、受保护区域无法编辑，或当前软件无法保留讨论，交付独立的 HTML 页位意见单，配合原稿查看。旧式 `.ppt` 用 PowerPoint 打开，在副本上另存并核对页序、图表、备注和动画。含宏原稿保留原格式。若因加密、损坏或只提供截图而无法提取，按实际能看到的页记录位置和意见。

## 提取、写入和回查

工具需要 Python 与 `lxml`。以下命令由执行审阅的编辑在 Skill 目录运行。清单和意见数据放临时目录，用户无需准备。输出文件名应为新名字。

```text
python scripts/review_pptx.py inspect 原稿.pptx --output 页清单.json
python scripts/review_pptx.py annotate 原稿.pptx 意见.json 原稿-审阅.pptx
```

1. 批注中的页码一律按原稿编辑视图编号。先看 `slide_show.selection`，再结合指定起止页或 `slide_show.custom_shows` 中的实际页序复核前后衔接。自定义放映可能先讲第 3 页再讲第 1 页。互动跳转与动画仍须实际播放核对。完整审稿另读未参加本次放映的页，区分“现场未展示”和“文档未提供”。
   逐页核对隐藏状态、段落、对象和 `manual_review`。`title_hidden` 标明页题或其所在的组已隐藏。`title_off_slide` 标明顶层、未旋转的页题框按页上坐标可确定位于画面外，无障碍导航有时采用这种放置方式。两类标题都可帮助定位。判断听众实际看到了什么，要核对放映画面，尤其是坐标继承自版式、对象经过分组或旋转时。普通文本框做页题时，清单的标题字段可能为空。表格按可见合并单元格的起点定位。流程图的箭头与连接线可从 `visual_objects` 选择，箭头方向按实际页面目视确认。图内文字、母版与特殊对象应在编辑器或渲染页补读。
2. 将清单返回的 `source_sha256` 填入意见，按[批注分类](review-protocol.md#批注分类)填写大类、具体问题和说明。普通段落使用清单内的 `id`，引文逐字复制。下例假设第 3 页某段文字据第 2 页的表得出能耗结论，实际使用时替换段标识、引文和指纹。

```json
{
  "finding_schema": 2,
  "source_sha256": "从本次页清单复制",
  "findings": [
    {
      "paragraph": "S003/4/P1",
      "quote": "全部站点的耗电量下降",
      "category": "logic",
      "issue": "以单节点命中率推断各站点能耗",
      "comment": "第 2 页表 1 仅列单节点的缓存命中率，无法由该指标推出各站点的能耗变化。请引用各站点的耗电量记录，或将结论限定在已测指标。"
    }
  ]
}
```

3. 同一引文在一段重复时，填入 `start`，按段落中的 Unicode 字符从 0 计数。跨页问题选中首次影响理解的位置，在意见中注明关联页。对图片、原生图表或 SmartArt，先在页面上核实原字或区域，再填入 `visual_objects` 给出的对象标识。例如 `{"object":"S003/5","region":"右图纵轴刻度","category":"format","issue":"图例遮挡纵轴刻度","comment":"图例盖住了纵轴上方两个刻度值，影响读数。请将图例移至绘图区外并检查导出效果。"}`。逐字引文 `quote` 与区域 `region` 二选一。工具只核对对象和源文件版本，并注明“人工目视定位”。源文件变化后重新定位。确认无需标注且已做完整审阅时可传入空的 `findings`。若改交独立意见单，将最后一个文件名改为 `原稿-审阅.html`。
4. 重开最终文件，在放映视图看页面是否保持原貌，在批注窗格按页核对意见的数量和内容。逐条对照引文、对象和关联页，另核对备注来源与隐藏状态。图表、截图、视频、动画、链接文件及特殊放映路径按实际可见内容检查，具体记录能读到但无法直接圈选的范围，以及确实无法核实的部分。核验结束后执行[全文终检](../SKILL.md#交付前的全文终检)。

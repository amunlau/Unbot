# 科技汇报 PPT 的起草、润色与审阅

适用于技术评审、工程进展、试验报告和期刊论文汇报。新稿以中文为主。中文页题、表头及图注采用通行的技术用语，短语可承担标识、导航和列举的作用。英文页与双语内容按[中英文科技表达](chinese-english-style.md)核对。新写或润色的展示文字和演讲者备注均使用正式书面语。保存引语、规范原句、代码和原始记录的原貌。

## 按交付目的处理

- **依据材料起草。** 确认听众、汇报目的及已经提供的模板。先为每项主要判断找到工况、指标和依据，按“听众到这一页时已经知道什么”排页。结果页可以用有证据支持的判断作标题，方法页宜标明对象与方法，章节页可保留简洁的名词标题。对机制图说明输入、动作和可观察结果。交付可编辑的 `.pptx`，标题、正文、普通表格和可重建的数据图尽量采用原生对象。只有原图时保留图像和可编辑图注，避免凭像素重造数据。除用户另有要求，新稿逐页附正式书面备注，按本页需要说明读图顺序、方法、限制或来源。
- **润色已有 PPT。** 在副本上修改用户指定范围内的文字，沿用模板、母版、字号层级和作者术语。先校准主张与图表，再压缩重复解释。直接修改对应段落或单元格，保留文字格式、原生图表、分组、动画、链接和已有意见。只改页面时保留原备注，指定润色备注时也要与对应页面核对。若要挪页或移走定义，先查后面哪些页面依赖它；不要把唯一必要定义只挪到隐藏附录或备注里给主页腾位置。压缩或缩小框体后，须在实际画面上查看文字是否被裁切、图例是否挡住刻度、模板占位符是否残留。局部润色只改指定位置，在相邻页读回修改效果。
- **只检查或标注。** 保留源稿和正式展示内容，按[篇章衔接审阅](coherence-review.md)、[去 AI 味与文风](style-review.md)和[格式与版式审阅](format-review.md)逐页研判，再按[演示文稿批注与定位](pptx-review.md)记录或写入意见。批注与演讲者备注用途不同，编辑疑问放入审阅结果。作者同时要两种成果时，分别交付审阅结果和干净成稿。旧式 `.ppt` 可用兼容编辑器在副本上另存为 `.pptx`，先核对页序、内容、备注及影响理解的动画，再沿用对应位置。

## 把主讲路径、页面与备注分开阅读

在 Windows 和 Linux 上制作普通可编辑新稿，可使用宿主的演示工具或 Python 的 `python-pptx`。已有动画、宏、自定义放映或现代批注的稿件，应选能保留相应对象的编辑器在副本上处理。缺少合适的编辑器时，审阅可交付独立页位意见单。静态预览与动态放映的验收范围见[运行环境与文件验收](../README.md#运行环境与文件验收)。

1. **按实际放映顺序看一遍。** 连读可见页题，辨认研究问题、对象、工况、指标和结论。遇到“据此”“该方案”“第二阶段”等指向前文的词，沿已展示的页面回查相应结果或定义。单独阅读隐藏页、附录及备注，将其作为原稿的一部分检查。若唯一必要定义只在默认放映跳过的页上，应告诉作者听众在何处会失去线索。若有明确的自定义放映、按需跳转或会前材料，按真实使用路径判断。[PowerPoint 隐藏页说明](https://support.microsoft.com/en-us/powerpoint/hide-or-show-a-slide)
2. **在页面上追踪证据。** 读页题后指出哪条曲线、哪个表格单元格或哪段流程支持它。核对比较组别、分母、时间窗、坐标量及单位、图例和箭头含义。双栏页面分别确认标签属于哪一栏。结论依赖局部区间时，让读者能在相应区间找到依据。例如图只给出稳态误差，页题却宣称“动态响应改善”，应指出图中缺少能支持动态判断的响应过程或指标。《农业工程学报》的图表要求可供核对量、单位和图例，投稿版面格式依该刊适用范围执行。[工程期刊图表说明，第 10 节](https://nygcxb.ijournals.cn/nygcxb/site/menus/4)
3. **按听众需要判断首次引入。** 通行术语、图中已标明的部件和前页已定义的缩写可以直接使用。项目特有的名称若第一次就充当推导前提，应定位它的定义或作用。例如概览页提出“切换后为何仍会丢帧”，下一页用时序图说明切换期间缓冲区溢出，构成合理的问题与解答。若后页直接把“窗口 W”代入阈值公式，之前只有词名，听众仍需知道 W 是时长还是样本数。只标出缺少的定义，按材料决定是否已能补写。
4. **交叉读页面、图注和备注。** 先单看页面能否识别判断和关键限制，再读备注是否扩大主张、保留了旧版数据或把图中 A 组称作 B 组。只写在备注里的“仅在空载条件下”无法限制独立分发页面上“任何负载均可运行”的断言。备注可以提供推导细节和来源。仅在理解当前页面或作出决定确实依赖该信息时，建议把它移到可见处。

工程教学的一项 110 人对照实验发现，采用结论与视觉证据配合等多项设计的学生组对所讲内容理解得更好。该实验同时改变了多项设计，目录、过渡、方法等页应按本页任务选择标题。关于机械系统动画的三项实验说明，先熟悉必要部件及其状态有助于受试学生迁移所学。专家评审会可直接使用听众掌握的概念。折线图与图注的阅读实验还发现，图中突出的特征会影响读者提取的信息，图注强调较小区间时尤其应让读者找得到所指位置。[工程演示对照实验](https://www.writing.engr.psu.edu/ae_comprehension.pdf) · [机械系统先备知识实验](https://pubmed.ncbi.nlm.nih.gov/12240927/) · [折线图与图注阅读实验](https://dhkim16.github.io/chart-caption-takeaway/)

## 把意见落在读者遇到障碍的地方

给出实际文件中的页序、页题和对象。文字附逐字引文，表格细化到行列，备注细化到段落。纯视觉问题可用对象和区域定位，例如“右图虚线与实线共用同一图例而未注明组别”。跨页问题标在首次依赖缺失信息或推出过强结论的位置，并指出关联页及证据。图内文字无法辨认时说明可判读的范围。

例如第 3 页报告整机端到端时延的空载试验，最大实测值为 7.2 ms，验收限值为 8 ms。第 5 页却写“设备在所有工况下均满足时延要求”。可在第 5 页标注“【篇章与逻辑｜后文丢掉了仍然有效的限定】第 3 页的数据支持本次空载试验达标。请将结论限定于已测工况，或补充其他工况下整机时延与验收限值的比较记录。”若附录已有其他工况的数据，应先核对指标和判据。前文没有限定测量范围，又找不到关键记录时，按【依据待核】处理。[篇章衔接审阅](coherence-review.md)

## 在将交付的文件上终检

执行[全文终检](../SKILL.md#交付前的全文终检)。重开最终 PPTX，逐页查看实际画面，同时读回表格、图例、标题和备注。检查单位、上下标、图文裁切、文字遮挡及位置错配，并查看文字是否被页边裁切或遮挡、越出文本框的文字是否仍完整可读、可见页是否残留模板占位符、对象是否被误移出画面，以及唯一必要定义是否只出现在隐藏附录。涉及动画逐步揭示或跳转时，在具备相应能力的演示环境验证实际顺序。需要无障碍阅读时，另查阅读顺序窗格、分组和替代文字。文本抽取顺序、对象叠放顺序、屏幕阅读顺序与放映时的出现顺序可能不同。条目、正反例与生成约束见[格式与版式审阅](format-review.md)。[PowerPoint 视图说明](https://support.microsoft.com/en-us/powerpoint/training/choose-the-right-view-for-the-task-in-powerpoint) · [Microsoft 阅读顺序与分组说明](https://support.microsoft.com/en-us/powerpoint/make-slides-easier-to-read-by-using-the-reading-order-pane)

对审阅件逐条核对页序、原句、意见及所引依据。对干净稿复查变更页、上下游页面、备注和摘要中的同一事实。修正后重新保存并复查。图中文字、外链图表、媒体或动画确实无法检查时，交付说明列明具体页和受影响的判断。仅有预览或摘录时，审阅结论限定于实际可见的材料。

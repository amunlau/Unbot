# 科技写作的证据与审阅判据

资料核对日期为 2026-11-10；去 AI 味的可执行检查于 2026-11-11 收入[去 AI 味与文风](style-review.md)。以下规则用于组织专业书面稿，并在已有文档中定位读者确实会遇到的问题。文中数值和情境示例均为教学用例。

## 从材料起草一段可核对的结论

假设试验记录只有四项：单节点回放、同一批输入、A 与 B 的峰值内存分别为 2.0 GB 和 1.6 GB、并发工况未测。报告可以写成：

> 在输入相同的单节点回放中，A、B 的峰值内存分别为 2.0 GB 和 1.6 GB。此次试验未覆盖并发工况。

这两句也可用作独立摘要的一部分。正文另有方法和采集过程时，摘要不必重述所有步骤；“单节点”却不能随之删去。“B 的内存利用率更高”变更了指标，“适用于生产环境”扩大了适用范围，“充分展现了明显优势”没有增加读者可用的信息。起草时只写材料支持的内容，审阅时区分三处不同问题，尤其不要把前两处技术失真仅归为措辞生硬。

Peters 与 Chin-Yee 比对了 10 种模型生成的合计 4900 份科学摘要及其对应原文，发现部分模型会扩大原结论适用范围。因此，在压缩长文、写摘要、由数据表起草结论时，先查失去哪些限制，再查修饰词。研究测试的是特定条件下的模型摘要，不提供单句作者身份判据。[原始研究，2025](https://doi.org/10.1098/rsos.241776)

## 写作与批注的成对判断

| 阅读时遇到的情形 | 起草或润色时 | 审阅已有文档时 |
| --- | --- | --- |
| 长段从“随着……不断发展”写起，随后才说明本研究的问题 | 从真实矛盾、已知技术缺口或任务条件落笔。领域变化确实解释了研究设计时，保留它并交代具体关系。 | 若背景删去后研究动机丝毫未变，可标该句并指出信息重复。若新规生效日期改变了纳入条件，则保留有关时间和背景。 |
| 每节都用同一种导语和“意义重大”收尾 | 方法交代操作，结果报告观测，讨论解释边界。确有相反预期时用转折，后一项推进同一判断时用递进。 | 跨段落出现同一问题时，标一个代表位置，在意见中列出其他章节。固定的结构式摘要、条款编号和对称的实验组别可以帮助读者定位，无需打散。 |
| “上述分析表明该方案可显著提升性能” | 回查对应的分析、比较对象和指标。统计显著性、工程效应大小、是否满足验收门槛应分别表述。 | 精确指出缺哪一项。如材料只给出 8.1 和 7.9 两个均值，可建议“报告指标、单位和测试条件”；如作者确实做了检验，请其指明结果所在位置。不要自行计算显著性。 |
| “大量研究证明……”后接一串引文 | 按文献实际支持的命题组织，一条句子容纳多个命题时可拆句并分别保留引文。 | 分开问“条目可定位吗”和“该来源支持这项陈述吗”。只看得到书目时记“需核对支持范围”。DOI 可解析只能核实条目标识；全文未查到时不声称引文虚构。 |
| “系统应及时、可靠地完成处理”出现在验收条款 | 优先使用原规范给定的触发条件、责任对象、可观察输出、阈值与测量方法。材料只有设计目标时，保持目标语气。 | 可批“‘及时’尚无判定条件，验收时无法判定通过。请引用既定阈值及计时起止点。”不得为补齐句子猜测毫秒数。若只是总体目标且后文已定义，指向相应条款即可。 |
| “目前新版本已全面支持导出”写在长期维护的手册中 | 材料有版本号时写明哪个版本支持哪种格式。材料无版本或日期时，应先确认手册所述的版本范围。 | 检查“目前”“新”的参照点。带报告日期的阶段进展、发布记录或真实的“尚未完成”具有时间含义，应保留。 |
| 多次使用同一术语、被动式或有条件的情态词 | “随机分配”“关联”“置信区间”等有学科含义时原样使用。用“可能”表示真实不确定性；使用主动或被动取决于此处需要区别谁操作、谁承担责任。 | 单凭反复出现、词较长、英文出现 *may*、句子使用被动式等，不足以批注。若 “were excluded” 隐去了谁按什么标准排除样本，才就可复现性提出具体问题。 |

这些判断的依据各有适用范围：

- **篇章与摘要。** 科技部对 GB/T 7713.3—2014 的说明列出了科技报告的典型组成和图表编号。长江大学期刊中心区分报道性、指示性等摘要；《青岛理工大学学报》对本刊摘要强调边界条件和具体结果，并要求中英文摘要对应。真实模板优先，期刊的字数、人称和结构不应外推到所有技术文档。Gopen 与 Swan 从读者理解科学问题的角度指出，句首承接已知对象、句末安排新信息可以改善读序，但具体语境可有例外。[科技部，2014](https://www.most.gov.cn/ztzl/jlkjbg/kjbgxxjl/201409/t20140915_115564.html) · [长江大学期刊中心，2013](https://qks.yangtzeu.edu.cn/info/1045/1065.htm) · [《青岛理工大学学报》投稿须知](https://qdjg.cbpt.cnki.net/EditorD2N/PromptPageInfo.aspx?c=1&t=v) · [Gopen 与 Swan，1990](https://www.cs.tufts.edu/comp/105-2016s/readings/sci.html)
- **统计和引用。** ICMJE 对医学论文建议在结果中报告百分比所对应的绝对数，结论应与研究目的和实际数据一致。Gelman 在其研究博客用自己与 Stern 的工作说明，两组分析中一个达到显著性、另一个未达到，仍不能据此断言两组效应不同。Walters 与 Wilder 对两种模型生成综述中的 636 条书目进行核查，发现存在编造条目及真实文献的书目信息错误；该研究的错误率不能移用于本稿。[ICMJE 写作建议](https://www.icmje.org/recommendations/browse/manuscript-preparation/preparing-for-submission.html) · [Gelman 研究博客，2006](https://statmodeling.stat.columbia.edu/2006/08/24/updated_paper_o/) · [Walters 与 Wilder，2023](https://doi.org/10.1038/s41598-023-41032-5)
- **需求、量值和时效。** NASA 的需求清单要求用可验证的方式界定预期行为。IETF RFC 8174 说明，在采用 BCP 14 的文档中，规范关键词有特定的大小写约定；其他项目须查本项目的定义。NIST 的 SI 写作指南将数值、单位及代表的量结合解释，尤其适合核对表头、倍率和正文引用。Google 开发者文档指南区分长期有效的说明与具有明确时间背景的内容。[NASA 需求清单，2023 年更新](https://www.nasa.gov/reference/appendix-c-how-to-write-a-good-requirement/) · [RFC 8174，2017](https://www.rfc-editor.org/rfc/rfc8174.txt) · [NIST SP 811，第七章](https://www.nist.gov/pml/special-publication-811/nist-guide-si-chapter-7-rules-and-style-conventions-expressing-values) · [Google 文档时效指南](https://developers.google.com/style/timeless-documentation)
- **作者与学科惯例。** 曼彻斯特大学 Academic Phrasebank 对解释结果、限定推广范围等书面功能分别给出惯用表达。欧洲科学编辑协会的写作与翻译指南建议精确选词，在定义缩略语后保持一致。Academia Stack Exchange 一场关于科技论文语态的讨论中，答主用区别本研究与他人实验解释了为何有时必须写出施事者；其他回答转述了编辑偏好。论坛意见只用于发现真实分歧，不能替代目标期刊要求。[曼彻斯特大学写作资源](https://www.phrasebank.manchester.ac.uk/using-cautious-language/) · [EASE 写作与翻译指南，2018 版](https://ease.org.uk/publications/author-guidelines-authors-and-translators/) · [Academia Stack Exchange 原讨论，2017](https://academia.stackexchange.com/questions/99710/is-it-a-must-to-write-a-paper-in-passive-third-person-for-all-types-of-papers-i)

## 如何使用中英文学术语料研究

Kobak 等分析了 2010—2024 年间逾 1500 万篇 PubMed 生物医学摘要的年度用词变化。研究的推断单位是文献群体。Mo 与 Wu 以应用语言学论文为材料，将 100 篇中文人工摘要与 DeepSeek-R1 根据相同文章生成的摘要配对。模型摘要覆盖的修辞功能较多，功能顺序的变化较少。两项研究都能解释编辑为什么应查看套语密集处的上下文。它们不能推出“一见特定词即标警告”，也不能设定跨学科、跨语言的统一阈值。[Kobak 等，2025](https://arxiv.org/abs/2406.07016) · [Mo 与 Wu，2026](https://doi.org/10.1016/j.acorp.2026.100206)

据此，书面审阅须回答一个具体问题：作者接受这条意见后，读者将能更准确地辨认哪个对象、条件、证据或动作？例如“第 3 节‘同样有效’没有说明与哪种方案比较，请补出对照组或指向已有的比较结果”就可以执行。若唯一的理由只是“像 AI”，撤去该条意见。

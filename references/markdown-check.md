# Markdown 的结构辅助核对

用于已有 Markdown 的润色或重写。先保留原文件，再对照实际成稿；仅审阅时正文不变，仍按审阅流程核对意见与原句。本工具是标准库实现，Python 3.9 及以上可运行，不修改输入文件。

```text
python "技能目录/scripts/check_markdown_structure.py" before.md after.md
python "技能目录/scripts/check_markdown_structure.py" before.md after.md --json
```

在文稿工作目录运行，将“技能目录”替换为技能安装目录的绝对路径；输入的相对路径以文稿工作目录为准。含空格的路径按所用终端语法加引号。输入接受 UTF-8 及 UTF-8 BOM，CRLF 与 LF 不作为内容变化。

## 核对内容

| 类别 | 识别与保护的内容 |
| --- | --- |
| `metadata` | 文件开头 `---` 到结束 `---` / `...` 的元数据原文 |
| `code` | 顶层反引号或波浪号围栏的标记、语言和正文；同一段内配对行内反引号的完整片段，可含软换行；疑似跨块配对会提示复核 |
| `math` | 显式 `$$...$$`、`\[...\]`、`\(...\)` 及符合下述约定的单美元行内公式 |
| `links` | 行内链接及图片的目标和标题、单行引用定义、引用标签和显式 HTTP(S)/mailto 自动链接（协议名不区分大小写）；不锁定可润色的链接显示文字 |
| `headings` | 顶层 ATX 和单行 Setext 标题原文；疑似多行 Setext 会记录候选整段并提示人工确认。文本改变可能影响渲染器生成的锚点 |
| `anchors` | HTML 标签中的 `id` / `name` 属性和 `{#id}` 形式的显式锚点 |
| `tables` | 简单竖线表格的整行原文，包括表头、分隔行和数据；分隔单元格允许单个连字符；紧接无竖线的疑似数据行时提示复核范围 |
| `lists` | 保护列表缩进、标记、序号及空列表项。任务列表项开头的勾选状态（如 `[ ]`、`[x]`、`[X]`）随列表标记核对。步骤正文的先后含义另行复核。 |

这些类别按出现顺序比较，不只比较词频。代码、公式及元数据中的伪标题不按普通正文处理。单美元行内公式在同一行配对，边界内侧不留空白，结束符后不紧接数字。美元符号前有奇数个连续反斜杠时按字面处理，公式内的转义美元符仍属于公式内容。未配对的单美元符号视作普通文字。实际平台对货币、转义和数学扩展的解释仍需回读确认。

默认标题原文也受保护。作者已允许修改标题时，可仅放行 `headings`；如同时更改显式锚点，须在检查目录、书签和交叉引用后决定是否放行 `anchors`。改写表格文字同理，不能只为消除提示而放行整个表格。

```text
python "技能目录/scripts/check_markdown_structure.py" before.md after.md --allow headings
```

`--allow` 可重复指定，表示相应类别已有编辑授权，不代表授权变更已经核对正确。其他类别仍会检查；扫描限制不会因放行类别而消失。输出保留全部变化类别及实际放行项。JSON 仅包含类别、数量、诊断行号及检查范围，不包含原文片段。

## 如何处理结果

- 退出码 `0`：已识别类别中未发现未经放行的变化。继续核对事实与渲染，不称“语义全部保真”。
- 退出码 `1`：发现未放行的结构变化。回查实际差异，区分误改与已有授权的必要修改。
- 退出码 `2`：文件读取失败，或扫描遇到需人工确认的结构。检查终端说明；即使原稿已有未配对标记，也应说明限制，不以零差异证明完整检查。

这是有限扫描器，不是 CommonMark、GFM、HTML 或 TeX 的完整解析器。未闭合的显式公式、围栏、行内反引号和链接目标会提示人工判断；其中某些在 Markdown 中可以合法显示为普通文字。开头的 `---` 也可能是普通分隔线而非元数据。缩进代码、引用块及嵌套围栏等容器会提示扫描限制，按实际编辑器或渲染结果复核。多行引用定义、HTML 链接/表格、脚注、复杂数学环境和平台扩展不在完整支持范围，需另行核对。

以下边界情况即使前后文本一致，也返回 `scan-incomplete`，不因 `--allow` 放行而消除提示：

- 疑似多行 Setext 标题：记录候选整段，并要求在渲染中确认段落和标题边界。
- 行内反引号之间存在空行、标题、列表、围栏等已知或疑似块边界：不把中间结构屏蔽为代码，要求在实际渲染中确认。合法的段内软换行仍可保留在代码片段中。
- 链接的文字、目标或标题疑似跨越段落或其他块边界时，按提示检查实际渲染中的链接范围和目标。合法的段内软换行仍按链接语法处理。
- 竖线表格后紧接不含竖线的非空行，且没有已识别的块边界：它可能仍是表格数据行，需核对表格实际范围和各单元格归属。

以下变化可能在结构核对中通过，但仍会改变内容：

- 列表序号不动，把“断电、开盖”两步内容交换。
- 链接目标和出现顺序不变，交换对应的显示文字。
- 正文中的甲乙组数值对调，删除否定词，或改变前提与责任人。

数字和指定原样片段可另用 `check_literals.py` 辅助核对。两项工具都不能验证数值归属、科学主张、参考文献支持关系或自然度。交付前仍执行主技能规定的全文终检，并在实际渲染中确认表格、目录、链接与公式。

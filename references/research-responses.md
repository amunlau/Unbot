# 审稿回复、研究计划与项目建议

仅在任务包含审稿回复、投稿附信、研究计划、基金申请或工程项目建议时加载。沿用[编辑深度与作者校准](editing-modes.md)的修改边界和专业书面语要求。普通论文、技术报告不必增加本页栏目；这里的检查关系也不要求写成固定数量的标题。

## 审稿回复回应真实问题

按实际意见编号逐项核对“提出的问题、作者的立场、依据、处理状态、对应稿件位置”。先回答审稿人所问，再交代必要的解释和修改位置。涉及多个子问题时分别回应，不能只用礼貌性感谢代替答案。

- 保留意见原文或准确转述及其编号。实际引用的审稿意见属于受保护材料，不能为去口语或去模板化改动引文。
- 依据作者材料区分接受、部分接受、未采纳和待决定。没有作者立场时，写待确认项，不代作者答应新增实验、补数据或撤回结论。
- 区分已修改、拟修改、尚未完成和本轮不修改。报告“已修改”时，对照最终稿的实际内容与位置；页码可能随排版变化，交付前重核章节、页码或行号。
- 同一证据缺口被审稿人明确追问时，回应中的解释和限定有独立作用，不能按“重复防御”删掉。真正的反证、未采纳理由及替代分析也须保留。
- 必要的感谢、致歉和澄清可以保留，不强制每条回复使用同一礼貌套式，不添加作者没有表达的自责或承诺。

**状态保留例。** 审稿意见 2 要求补充温度循环试验。给定作者材料是：本轮不新增该试验，因为试验设备尚未到位；正文第 3.2 节末已注明温度循环尚未测试。对照最终稿确认后，可写：

> 关于意见 2，本轮修订未新增温度循环试验，原因是试验设备尚未到位。我们已在第 3.2 节末注明温度循环尚未测试，以明确现有结果的适用范围。

不能写成“新增试验验证了方案的可靠性”，也不能擅加试验完成日期。若作者仅计划修改第 3.2 节，应改用计划状态，不能提前报告完成。

投稿附信按作者提供的稿件信息和投稿要求组织。研究创新、作者同意、利益冲突或一稿多投等声明属于实质信息，不能当作惯例套话自动补入。已有正式声明按实际含义与适用模板处理。

## 研究计划与工程立项的论证关系

| 检查关系 | 具体判断 |
| --- | --- |
| 问题与目标 | 目标是否回答已提出的问题，是否说明要获得何种知识、性能或能力；“采用某模型”通常只说明方法，不能单独替代目标 |
| 目标与研究内容 | 每项内容解决哪一部分问题；保留彼此独立的任务，不为凑三项拆分或合并 |
| 内容与方法、验证 | 方法产生什么观察或结果，凭什么判断目标是否达到；已有判据、比较对象与适用工况要能对应，缺少时指出缺口，不自填阈值 |
| 前期基础与可行性 | 前期工作是否直接支持该任务；团队履历、设备清单不能自动证明关键技术可行，未到位设备和拟合作单位保留其状态 |
| 目标之间的依赖 | 后项是否必须等待前项成功；若任一前项失败会使其余任务无法开展，指出依赖和需要说明的应对，不能自行承诺备选方法已经可用 |
| 风险与替代路径 | 已知风险有无触发条件，材料提供的替代路径是否仍服务于同一目标；没有相关信息时提出待补项，不自动补泛泛风险段 |
| 预期成果与计划状态 | 区分已完成成果、拟开展工作和预期贡献；合理愿景可以保留，但不能转成已经验证的效果、必然成功或保证收益 |

**目标与方法的区别。** 给定材料为“拟比较两种检测策略；关注弱信号下的漏检率；计划用回放数据开展测试；尚未取得结果”，可写：

> 本项目拟比较两种检测策略在弱信号条件下的漏检率，计划利用回放数据开展测试。当前尚无实测结果。

如果项目要求明确验收标准，需补充已有的信号条件、数据来源和判定标准，不能凭写作需要设定漏检率上限。也不能把计划中的回放测试写成已完成的性能验证。

工程建议进一步核对责任主体、实施前提、资源状态及停止条件。供应商宣称、既有试验和本项目预期分别归属；不要把产品具备某功能直接改写成已降低成本、提高安全性或通过验收。

## 模板、交付与复核

具体机构、项目类别、年度的栏目、字数、页数和材料要求，按作者提供的当期通知或经核实的官方要求处理。要求核验最新规定时，先查对应项目的现行通知；没有核实则不声称已符合申报要求。不将固定的 NSF、NIH 或某一学科模板套到所有申请，也不以“前三页决定成败”等说法制定统一篇幅配额。

指定模板的栏目与编号优先保留。纯润色发现论证缺口时，在正文外给出具体位置和所缺材料；仅审阅时使用既有六类批注，例如“【篇章与逻辑｜后续目标依赖未说明】”或“【依据待核｜关键设备可用状态待核】”。获准实质改写后，仍只根据材料修正，默认交付成稿及必要的实质变更说明。

交付前完成[全文终检](../SKILL.md#交付前的全文终检)。审稿回复逐项核对意见、回应、正文实际修改和位置；研究计划核对目标、路线、前期基础、进度及预期成果的一致性。同步制作 PPT 时，页内文字、图题和备注同样区分计划与已取得结果，不能把尚未落实的资源写成现有条件。
